## TLDR

I led and built internal tooling for Open Project @ Berkeley, supporting 150+ members, 10+ teams, and 200+ applications per semester.

The platform included Next.js, Supabase, PostgreSQL, Drizzle ORM, and a CAS-authenticated application system tied into Berkeley login.

Beyond the app itself, I introduced CI/CD workflows, templates, documentation, onboarding support, and review patterns for 15+ developers across teams.
