A productivity extension for managing your calendar straight from Raycast — built in
TypeScript and React, integrated with macOS calendar software via AppleScript, and used
by over 10,000 people.

## The problem

Calendar management is full of tiny context switches: opening the calendar app,
clicking through dates, finding the right event, and making a small edit that should
have taken seconds. Raycast was the right surface because the workflow starts from the
keyboard and stays there.

## What I built

I built a TypeScript and React extension that exposes calendar actions directly inside
Raycast. The extension talks to macOS calendar software through AppleScript, so users
can manage events without leaving the launcher-style workflow.

## The results

The extension reached 10,000+ users, which made the project less about a neat local
script and more about shipping a small productivity surface that had to be predictable,
keyboard-first, and reliable for real daily use.
