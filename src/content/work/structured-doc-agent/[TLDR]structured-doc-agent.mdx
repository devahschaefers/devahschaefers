## TLDR

- Built an LLM document-editing agent that makes targeted tool-call edits over an intermediate representation instead of regenerating whole documents.

- Constrained model actions through edit tools so multi-step changes stay local to the intended document regions.

<Metric value="60%" label="less manual editing time" />

- Added post-edit validation to preserve structure and avoid the usual structured-output drift.
