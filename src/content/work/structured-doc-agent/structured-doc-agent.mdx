Letting an LLM edit a structured document by regenerating it is a recipe for broken
output — it'll quietly drop a field, mangle nesting, or hallucinate structure. I built
an agent that edits documents the safe way: through constrained tool calls over an
intermediate representation, so every change is deliberate and valid.

## The problem

Freeform "rewrite this document" prompts give the model too much rope. For anything
with real structure, you need edits that are *targeted* and *verifiable* — the model
should say "change this field" rather than re-emit the whole thing and hope it stays
consistent across multiple steps.

## An intermediate representation

The core idea is an intermediate representation the agent operates on via tool calls.
Instead of producing raw output, the model proposes structured edits, which keeps
multi-step changes safe and consistent — the document can't drift into an invalid state
between steps.

## Validation

I paired that with a validation system combining **tool-level constraints** — bounding
what each edit is even allowed to do — with **post-edit checks** that verify the result
after the fact. Two layers, so a bad edit is caught either before it happens or
immediately after.

The payoff was concrete: a 60% reduction in manual editing time, with the structure
staying intact instead of needing cleanup.
