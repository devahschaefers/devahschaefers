## TLDR

I worked on predicting chip power consumption from netlist structure before fabrication, turning raw netlists into graph data suitable for machine learning.

The pipeline used PyTorch Geometric, graph features, and model benchmarks across linear regression, random forests, gradient boosting, and GNNs, evaluated on **MAE, RMSE, and MAPE**.

I also used SHAP analysis so the model could explain which structural features were driving the power estimates.
