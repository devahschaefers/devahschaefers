Every student knows the ritual of wandering the halls looking for an empty classroom to
study in. The information to end that exists — it's just locked inside hundreds of
separate class schedules. I built the data pipeline that freed it.

## The problem

Berkeley has 600+ classrooms, each with its own schedule, and no single view of which
rooms are actually open right now. The data is public but scattered, unstructured, and
huge — exactly the kind of thing that's tedious by hand and trivial once it's modeled.

## The scraper

I built an asynchronous web scraper that fires 10,000+ automated HTTP requests per run
and collects 100K+ classroom availability data points. Going async is what made it
viable — it cut end-to-end collection time by roughly **100x** compared to a sequential
approach.

## Structuring it

Raw schedules aren't a product. I turned the data for 600+ classrooms into a structured
JSON availability model — a clean representation of when each room is free — which then
powered a student-facing tool querying 100K+ records to find open study spaces on
demand.
