## TLDR

- Built the data pipeline behind a Berkeley open study-space finder by scraping scattered classroom schedules across 600+ classrooms.

- Ran **10,000+ HTTP requests per collection run** and converted fragmented public schedules into **100K+ structured availability records**.

- Turned raw classroom availability into queryable JSON models students could use in real time.
