## TLDR

I built the data pipeline behind a Berkeley open study-space finder by scraping scattered classroom schedules and converting them into structured availability data.

The scraper ran **10,000+ HTTP requests per collection run** and produced **100K+ availability records** across 600+ classrooms.

<Metric value="~100x" label="faster collection" />

The useful part was turning public but fragmented schedules into a queryable model students could use in real time.
